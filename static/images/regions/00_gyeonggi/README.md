## 참고
- 틀에 있는 `White` 변형(다크 모드용)은 받지 않았습니다. 고양시, 남양주시, 파주시에 있었습니다.
- 시 아래의 일반구와 읍·면·동 로고는 범위에서 제외했습니다. 문서의 틀에는 일반구 CI가 없었습니다.
- 수원시 CI는 파일 안에 흰색 배경 사각형이 포함되어 있습니다.
- 로고의 권리는 각 지방자치단체에 있습니다. 이용 조건은 발표·배포 전에 확인하세요.
