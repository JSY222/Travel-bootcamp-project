# 제주특별자치도 행정시 로고

나무위키 개별 문서 [제주시](https://namu.wiki/w/%EC%A0%9C%EC%A3%BC%EC%8B%9C)와 [서귀포시](https://namu.wiki/w/%EC%84%9C%EA%B7%80%ED%8F%AC%EC%8B%9C)의 정보 상자(2026-10-13 기준)에서 받은 CI입니다. [제주특별자치도](https://namu.wiki/w/%EC%A0%9C%EC%A3%BC%ED%8A%B9%EB%B3%84%EC%9E%90%EC%B9%98%EB%8F%84) 문서의 하위 행정구역 틀에는 행정시 CI가 없어 개별 문서에서 받았습니다. 파일 이름은 `지역번호_영문명.svg` 형식이고, 번호는 임시로 `00`입니다.

| 파일 | 행정시 | 나무위키 이미지 이름 |
| --- | --- | --- |
| `00_jeju-si.svg` | 제주시 | 제주시 CI |
| `00_seogwipo-si.svg` | 서귀포시 | 서귀포시 CI |

## 참고
- 제주도는 자치시·군이 없고 행정시 2곳(제주시, 서귀포시)뿐입니다.
- 출처 문서는 각각 나무위키 `제주시`, `서귀포시` 문서입니다. 두 CI 모두 도 CI(Jeju 로고와 "제주특별자치도 Jeju Special Self-Governing Province")에 시 이름을 붙인 형태입니다.
- 문서 본문에 있는 옛 휘장·CI(제주시 휘장 ?~1999, 제주시 CI 2000-2006, 서귀포시 구 CI 등)와 북제주군·남제주군 이미지는 받지 않았습니다.
- 로고의 권리는 각 지방자치단체에 있습니다. 이용 조건은 발표·배포 전에 확인하세요.
