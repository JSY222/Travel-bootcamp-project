## 참고
- 틀에는 8개 시와 10개 군이 모두 있었고, 시·군 CI만 받았습니다. 틀에 일반구나 읍·면·동 이미지는 없었습니다.
- 틀에 있는 도 휘장(`경상남도 휘장 White`, 다크 모드용)은 받지 않았습니다.
- `00_haman-gun.svg`(약 377KB)는 다른 파일보다 훨씬 큽니다. 배포 전에 SVG 최적화를 고려하세요.
- 로고의 권리는 각 지방자치단체에 있습니다. 이용 조건은 발표·배포 전에 확인하세요.
