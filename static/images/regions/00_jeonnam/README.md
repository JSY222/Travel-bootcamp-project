## 참고
- 전라남도는 광주광역시와 통합 중이라(전남광주통합특별시) 통합 전 기준으로 저장했습니다. 전남 소속 시·군 22곳(5개 시, 17개 군)만 이 폴더에 모았고, 광주광역시 자치구는 `00_gwangju/`에 있습니다.
- 틀에 있는 광주광역시 자치구 이미지와 읍·면·동 단계 이미지는 받지 않았습니다.
- 로고의 권리는 각 지방자치단체에 있습니다. 이용 조건은 발표·배포 전에 확인하세요.
