## 참고
- 강원특별자치도의 7개 시와 11개 군이 모두 포함되어 있습니다.
- 틀에 있는 `White` 변형(다크 모드용)은 받지 않았습니다.
- `00_hwacheon-gun.svg`는 약 240KB로 다른 파일보다 훨씬 큽니다.
- 로고의 권리는 각 지방자치단체에 있습니다. 이용 조건은 발표·배포 전에 확인하세요.
