## 참고
- 시·군·구 로고는 시·도별 하위 폴더에 둡니다. 폴더 이름은 해당 시·도 파일과 같은 `지역번호_영문명`입니다(예: `00_seoul/`). 현재 만들어 둔 하위 폴더는 다음과 같습니다.

  | `00_incheon/` | 인천광역시 구·군 | 11 |

  - 인천은 2026년 행정구역 개편 이후 문서 기준이라 제물포구, 영종구, 서해구, 검단구가 있고 기존 중구·동구·서구는 없습니다.
  - 제주의 제주시와 서귀포시는 제주특별자치도 문서에 CI가 없어서 각 시 문서의 정보 상자에서 받았습니다. 도 CI에 시 이름을 붙인 형태입니다.
  - 세종특별자치시와 전남광주통합특별시는 이번 작업 대상에서 제외했습니다.
  - 100KB가 넘는 파일: `00_chungnam/00_geumsan-gun.svg`(445KB), `00_gyeongnam/00_haman-gun.svg`(376KB), `00_gangwon/00_hwacheon-gun.svg`(234KB), `00_gyeongbuk/00_yeongdeok-gun.svg`(200KB), `00_gyeongbuk/00_yeongyang-gun.svg`(174KB), `00_daegu/00_jung-gu.svg`(459KB), `00_busan/00_jung-gu.svg`(126KB), `00_busan/00_busanjin-gu.svg`(111KB). 웹에서 많이 쓰면 SVG 최적화를 고려하세요.
- 파일 이름은 `지역번호_영문명.svg` 형식입니다. 지역번호가 아직 정해지지 않아 모두 임시로 `00`을 붙였으며, 확정되면 앞자리만 바꾸면 됩니다.
- 틀의 광역자치단체는 16곳입니다. 광주광역시와 전라남도 자리에는 `전남광주통합특별시`가 있고, 휘장 대신 **임시 로고**(글자만 있는 로고)가 올라와 있습니다. 정식 휘장이 나오면 교체해야 합니다.
- 틀에 있는 `White` 변형(다크 모드용)은 받지 않았습니다.
- `00_gwangju.svg`와 `00_jeonnam.svg`는 각 문서의 현행 휘장입니다. 문서에는 이전 휘장(광주 1987-, 전남 2000-)도 있지만 받지 않았습니다.
- `00_jeonnam.svg`의 노란 사각형은 배경이 아니라 상징을 이루는 도형이라 투명으로 만들 수 없습니다.
- 통합특별시가 정식 출범한 뒤에는 `00_gwangju.svg`, `00_jeonnam.svg`를 계속 쓸지 `00_jeonnam-gwangju.svg`로 합칠지 팀에서 정해야 합니다.
- 로고의 권리는 각 지방자치단체에 있습니다. 나무위키 문서 본문의 라이선스(CC BY-NC-SA 2.0 KR)가 이미지 파일에 그대로 적용되는지는 확인하지 못했으므로, 발표·배포 전에 이용 조건을 확인하세요.
