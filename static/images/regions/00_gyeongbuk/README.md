## 참고
- 틀에 있는 시·군 22곳의 CI를 모두 받았습니다. 시 아래의 일반구와 읍·면·동 이미지는 틀에 없었습니다.
- 군위군은 대구광역시로 편입되어 경상북도 틀에 없습니다. 대구 폴더(`00_daegu`)에 있습니다.
- 로고의 권리는 각 지방자치단체에 있습니다. 이용 조건은 발표·배포 전에 확인하세요.
