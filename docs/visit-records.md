# 방문 기록

지도에서 장소 마커 또는 목록을 누른 뒤 팝업의 ‘사진·리뷰로 방문 기록 남기기’를 사용합니다. 로그인한 회원만 저장할 수 있으며 첫 저장에는 사진과 리뷰가 모두 필요합니다.

- 사진: JPG / PNG / WebP, 최대 5MB. 리뷰: 공백을 제외하고 1~2000자.
- 같은 회원·분류·장소의 기록은 하나만 저장합니다. 다시 저장하면 기존 기록을 수정하며, 새 사진을 생략하면 기존 사진을 유지합니다.
- 지도 체크와 프로필 목록은 서버의 사용자별 기록을 사용합니다. 다른 계정의 기록은 표시하지 않습니다.
- 프로필은 관광지·맛집·행사별 목록과 각 분류의 방문 수, 전체 등록 장소 수 대비 총 방문 수를 표시합니다. 총 방문 수는 중복 없는 장소 수입니다.
- 사진과 리뷰는 `member_visits` 테이블에 함께 저장합니다. 별도 업로드 폴더는 없습니다. 배포·이전 시 DB 백업에 이 테이블도 포함하세요.
- 테이블은 방문 기록 조회/저장 시 자동 생성합니다. CREATE 권한이 없는 서버에서는 관리자가 `db/member_visits.sql`을 먼저 실행하세요. 기존 테이블을 삭제하지 않습니다.
- DB의 `max_allowed_packet`은 사진과 SQL 요청을 수용할 수 있어야 합니다(예: 16MB 이상).

검증: `python -m unittest discover -s tests -p test_visits.py`로 모의 DB 기반 API 테스트를 실행합니다. 로그인·CSRF, 잘못된 입력과 파일 크기, 신규 저장과 기존 사진 유지, 사진의 사용자별 접근, 목록과 분류별 전체 건수를 검증합니다. 실제 MariaDB와 브라우저 동작 확인은 별도입니다.
