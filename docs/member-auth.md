# 회원가입과 로그인

- `/signup`: 이름, 생년월일, 아이디, 비밀번호, 주소지, 여행 스타일을 입력합니다.
- 여행 스타일은 안내받은 다섯 종류 중 하나 이상 선택합니다.
- `/api/signup`, `/api/login`, `/api/logout`은 POST JSON 요청과 세션 CSRF 토큰을 사용합니다.
- 회원가입과 로그인 시 `members` 테이블이 없으면 자동 생성합니다. DB 사용자에게 CREATE 권한이 없는 환경에서는 관리자가 `db/members.sql`을 먼저 실행하세요. 기존 여행 데이터는 삭제하지 않습니다.
- 비밀번호는 Werkzeug 해시로 저장합니다. 사용자명에는 UNIQUE 제약을 적용합니다.
- 배포 환경에서는 `.env`의 `SECRET_KEY`에 충분히 긴 임의 문자열을 설정하세요. 설정이 없으면 서버 재시작 때 로그인 세션이 초기화됩니다. HTTPS 배포에서는 `SESSION_COOKIE_SECURE=True`도 설정하세요.
- 테스트: Flask 테스트 클라이언트와 모의 DB로 페이지 렌더링, CSRF, 입력 검증, 가입, 중복 아이디, 미등록 아이디, 비밀번호 확인, 로그인과 로그아웃을 확인했습니다. 실제 MariaDB 연결과 브라우저 화면은 별도 확인이 필요합니다.
