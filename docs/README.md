## 파일 이름

현재 문서들은 `YYYY-MM-DD_제목_작성자` 형식을 따르고 있습니다(예: `2026-10-13_지역로고수집_작업일지_양재덕.md`). 새 문서도 같은 형식을 쓰면 날짜순으로 정렬되고 작성자를 알아보기 쉽습니다. `db erd.md`는 이 형식이 아니며, 지금은 그대로 둡니다.

## 올릴 때

- 형식은 정해져 있지 않습니다. 회의록은 Word(docx), 기술 문서는 마크다운(md)을 쓰고 있습니다. md는 GitHub에서 바로 읽히고 변경 내역이 보이므로 가능하면 md를 권장합니다.
- 이 저장소는 공개 저장소입니다. DB 접속 정보 같은 비밀값, 개인정보, 공개하면 안 되는 자료는 올리지 마세요.
