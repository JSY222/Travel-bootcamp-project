# 2026-10-13 지역 로고 수집 작업일지

작성: 양재덕

지도에서 지역을 고르고 스탬프를 모으는 기능에 쓸 지역 로고 이미지를 모았습니다. 시·도 18곳과 그 바로 아래 행정구역(구, 시, 군, 제주 행정시) 229곳, 모두 SVG 247개를 `static/images/regions/`에 정리했습니다.

## 결과 한눈에 보기

| 구분 | 폴더 | 파일 수 |
| --- | --- | --- |
| 시·도 로고 | 시·도마다 폴더 1개(18개) 안에 1개씩 | 18 |
| 서울 자치구 | `00_seoul/` | 25 |
| 광역시 구·군 | `00_busan/`, `00_daegu/`, `00_incheon/`, `00_gwangju/`, `00_daejeon/`, `00_ulsan/` | 51 |
| 도 시·군, 제주 행정시 | `00_gyeonggi/`, `00_gangwon/`, `00_chungbuk/`, `00_chungnam/`, `00_jeonbuk/`, `00_jeonnam/`, `00_gyeongbuk/`, `00_gyeongnam/`, `00_jeju/` | 153 |
| 합계 | | 247 |

세종특별자치시는 하위 행정구역이 없어 시·도 로고만 있고, 전남광주통합특별시는 시·도 로고(임시 로고)만 있습니다.

## 폴더 구조와 이름 규칙

```
static/images/regions/
├── manifest.csv        파일별 출처와 비고(SVG 1개당 1행)
├── NOTICE.txt          출처, 사용 범위, 규칙, 주의점
├── 00_seoul/
│   ├── 00_seoul.svg    시·도 로고(폴더 이름과 같은 파일)
│   ├── 00_jongno-gu.svg
│   └── ...
└── 00_busan/ ...
```

- 폴더와 파일 이름은 `지역번호_영문명`입니다. 지역번호는 아직 정해지지 않아 모두 임시로 `00`을 붙였습니다. 확정되면 폴더 이름, 파일 이름, `manifest.csv`의 `path`를 함께 바꿔야 합니다.
- 시·도 로고를 자기 폴더 안에 넣어 시·도 하나가 폴더 하나로 정리되게 했습니다. 세종과 전남광주통합특별시도 자기 폴더를 만들어 예외 없이 같은 규칙을 따릅니다.
- 설명 파일은 `regions/` 바로 아래의 `manifest.csv`와 `NOTICE.txt` 두 개로만 관리하고, 하위 폴더에는 두지 않습니다.

## 진행 과정

1. **위치 결정**: 웹 앱이 정적 파일을 `static/` 아래에서 서빙하므로 `static/images/regions/`로 정했습니다. 기존에 있던 `static/images/local/`은 용도가 같아 정리했습니다.
2. **1차 시도와 폐기**: 처음에는 Wikimedia Commons의 시·도 상징 17개를 받았으나, 최신 여부가 불확실하고 경상남도만 PNG이며 형태가 제각각이라 폐기했습니다.
3. **출처 변경**: 최신 상태로 관리되는 나무위키의 [광역자치단체](https://namu.wiki/w/%EA%B4%91%EC%97%AD%EC%9E%90%EC%B9%98%EB%8B%A8%EC%B2%B4) 문서 틀에서 시·도 휘장을 받았습니다. 이 틀은 광주광역시와 전라남도 자리에 `전남광주통합특별시`가 있어 16곳이므로, 통합 전의 광주광역시와 전라남도 휘장은 각 문서에서 따로 받았습니다.
4. **하위 행정구역 수집**: 서울을 먼저 받아 방식을 확인한 뒤, 광역시 6곳과 도 8곳, 제주를 같은 방식으로 받았습니다. 각 시·도 문서의 기초자치단체 틀에서 구·시·군 CI만 받았습니다.
5. **정리**: 시·도 로고를 각자의 폴더로 옮기고, 폴더별 설명 파일을 `manifest.csv`와 `NOTICE.txt`로 통합했습니다.

## 검증

- SVG에 스크립트나 외부 주소 참조가 없는지 패턴으로 검사했습니다(247개 모두 통과, 빈 `<image>` 태그가 있는 파일 1개는 외부 참조가 아님을 확인).
- 안전 모드로 렌더링해 오류가 없는지 확인했고, 한 장에 모아 눈으로 확인했습니다.
- 내용이 같은 파일이 없는지 해시로 확인했고, `manifest.csv`의 247행이 실제 파일 247개와 정확히 일치하는지 확인했습니다.

## 알아둘 점과 남은 일

- **지역번호 확정**: 파일 이름의 `00`을 실제 번호로 바꾸는 일괄 변경이 남아 있습니다.
- **전남광주통합특별시**: 시·도 로고가 임시 로고(글자만 있음)입니다. 정식 휘장이 나오면 교체해야 하고, 출범 후 하위 행정구역 구성은 정해지지 않았습니다. 광주광역시와 전라남도의 하위 로고는 통합 전 기준입니다.
- **인천광역시**: 2026년 행정구역 개편 이후 문서 기준이라 제물포구, 영종구, 서해구, 검단구가 있고 기존 중구, 동구, 서구는 없습니다. 지도 GeoJSON이나 DB의 지역 이름과 다를 수 있어 연결할 때 확인이 필요합니다.
- **이용 조건**: 로고의 권리는 각 지방자치단체에 있습니다. 나무위키 문서 본문의 라이선스가 이미지에 그대로 적용되는지는 확인하지 못했습니다. 현재 용도는 시연과 발표이며, 그 밖의 용도로 쓰기 전에 확인이 필요합니다.
- **파일 크기**: 100KB가 넘는 SVG가 8개 있습니다(`manifest.csv`의 `note`에 '대용량'으로 표시). 웹에서 많이 쓰면 최적화를 고려해야 합니다.
- **배경**: 대부분 투명 배경이지만, 전라남도 로고의 노란 사각형처럼 디자인에 배경색이 포함된 것이 있어 어두운 배경에서 쓸 때 확인이 필요합니다.
- **코드 연결**: 아직 `map.js`나 템플릿에서 이 이미지를 쓰지 않습니다. 지도의 지역 코드와 파일을 어떻게 연결할지(예: `manifest.csv`나 별도 매핑)는 정해야 합니다.
