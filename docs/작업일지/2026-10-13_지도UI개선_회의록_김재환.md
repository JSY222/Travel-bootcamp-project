국내 여행 지도 UI 개선 회의록

Cityname · Travel bootcamp project

회의 일자: 2026년 10월 13일 (화) · 한국 시간

작성자 / 요청자: 김재환

진행 방식: 개발 작업 협의 및 코드 수정 · AI 코딩 도우미 지원

기록 범위: 본 대화에서 오늘 요청·수행한 지도 디자인 개선 및 오류 수정

# 1\. 회의 목적

Flask·MariaDB·Leaflet 기반 국내 여행 지도의 기존 탐색 기능을 유지하면서, 지역별 색상과 푸딩 같은 입체감, 상호작용 애니메이션, 깊이 있는 바다 표현을 개선한다.

# 2\. 최종 합의 사항

• 전국 17개 시·도를 서로 다른 고정 색상으로 표현한다. 지역 코드에 따라 색상을 유지한다.

• 모든 지역의 기본 높이를 동일하게 표현하고, 밝은 외곽 하이라이트와 부드러운 그림자로 입체감을 준다.

• 지역에 커서를 올리면 이름과 지역이 함께 약 8px 올라온다. 실제 클릭 영역은 움직이지 않는다.

• 지역 클릭 시 선택 기능을 즉시 실행하고, 별도의 장식용 복사본으로 약 0.62초 동안 통통 튀는 애니메이션을 재생한다.

• 지역 이름은 가장 큰 육지 영역의 내부 중앙에 가까운 위치에 배치한다.

• 전체 지도에서 작은 섬 조각과 복잡한 해안선을 정리하고 제주도·울릉도·독도의 표시 크기를 확대한다.

• 규칙적인 바다 반복 무늬를 줄이고, 크기·투명도·이동 속도가 서로 다른 물결과 빛 효과를 겹쳐 표현한다.

• 지도 기울기와 확대 시점 변경은 최종적으로 취소한다. 기울이기 이전 시점을 유지한다.

# 3\. 기능 유지 원칙

전국 → 시·도 → 시·군·구 또는 읍·면·동 탐색, 지역 확대, 장소 조회, 관광지·맛집·행사 필터, 장소 카드·팝업, 이전 단계 및 전국 복귀 기능을 유지한다. 원본 경계와 API 조회 조건은 보존하고 화면 표시용 경계와 좌표만 가공한다.

# 4\. 주요 논의 및 작업 경과

## ① 초기 입체 지도 디자인

기존 index.html, style.css, map.js를 확인하고 Leaflet을 유지한 채 SVG 조명 필터를 도입했다. 지역별 색상을 지정하고 입체 옆면·경계 음영·클릭 애니메이션·바다 장식을 추가했다. 최초 공유 링크의 내용은 불러오지 못해 당시 설명을 기준으로 작업했다.

## ② 커서 상승 효과 및 지역 이름 위치

커서가 올라간 지역의 시각적 복사본을 앞쪽에 배치하고 약 8px 상승시켰다. 이름도 함께 올라오도록 조정했다. 가장 큰 육지 영역을 선택하고 구멍을 제외해 내부 여유가 큰 위치를 계산함으로써 이름이 바다 쪽으로 치우치는 문제를 줄였다.

## ③ 지역 높이 통일 및 바다 일렁임

지역마다 따로 겹치던 입체 표현 대신 전체 육지에 하나의 공통 입체 바닥을 적용했다. 개별 지역은 외곽 조명으로 표현하여 높이를 통일했다. 실제 고도 데이터는 사용하지 않았다. 바다에는 물결 이동·상하 일렁임·빛 변화와 SVG 변형 효과를 추가했다.

## ④ 시점 변경 시도 및 원복

지도를 약 13% 확대하고 28° 기울임·8° 회전을 적용했으며 클릭 좌표 보정을 추가했다. 사용자의 시각적 선호에 따라 이 변경만 제거하여 직전 시점으로 복원했다. 해당 기울기·확대·좌표 보정 코드는 최종 상태에 포함하지 않는다.

## ⑤ 지역 클릭 및 지속적인 떨림 수정

장식용 복사본의 Leaflet 클릭 감지 클래스를 제거하고 pointer-events를 직접 차단했다. 실제 클릭 대상의 DOM 위치를 옮기지 않으며, 커서와 포커스 진입이 중복되어도 장식을 반복 생성하지 않도록 처리했다. 마우스 진입·이탈 이벤트를 정리하고 왼쪽 지역 버튼의 위치 이동을 없앴다. 클릭 실행은 애니메이션 완료 대기와 분리해 즉시 처리한다.

## ⑥ 섬·해안선 정리 및 주요 섬 확대

전체 지도에서는 상대적으로 작은 섬 조각을 줄이고 해안선 좌표를 단순화한다. 하위 지역에서는 세부 경계를 더 많이 유지한다. 제주도는 1.55배, 울릉도는 3배, 독도는 9배로 표시하며 해당 영역의 장소 마커와 카드 선택 시 이동 좌표에도 동일한 변환을 적용한다. 울릉도·독도 경계가 있을 경우 별도 이름을 표시한다.

## ⑦ 사진 참고 후 최종 시각 효과 강화

제공된 두 참고 사진의 외곽 조명과 수면 깊이감을 참고했다. 지역 가장자리의 밝은 테두리·윗면 하이라이트·부드러운 그림자를 강화하고 클릭 애니메이션에 상승·눌림·반동을 추가했다. 규칙적인 격자 장식을 숨기고 58개의 물결을 흩어 배치했다. 물결의 폭은 약 22~102px, 높이는 약 7~22px, 투명도는 약 0.15~0.55, 이동 주기는 약 22~49초로 다르게 설정했다.

# 5\. 변경 파일 및 역할

## templates/index.html

지역 표면·입체 바닥·바다 변형용 SVG 필터와 바다 장식 구조를 추가했다. 주요 섬 확대 표시 안내를 지도 하단에 반영했다.

## static/css/style.css

외곽 하이라이트·그림자·지역 상승·클릭 반동·다층 물결·빛 변화의 시각 효과를 적용했다. 버튼 위치를 고정하고 모바일 및 동작 줄이기 설정을 고려했다.

## static/js/map.js

지역별 색상, 화면 표시용 경계 정리와 섬 확대, 지역 이름 위치 계산, 커서 장식 복사본 관리, 즉시 지역 선택, 물결 생성, 확대된 섬의 마커·이동 좌표 정합성을 처리했다.

app.py, import_geojson_regions.py 및 DB 관련 파일은 본 대화의 디자인 작업에서 수정하지 않았다. 변경 사항은 로컬 파일에 저장했으며 Git 커밋 및 배포는 수행하지 않았다.

# 6\. 검증 결과 및 한계

• JavaScript 문법 검사와 Git diff 공백 검사를 수행했다.

• SVG 필터 XML 구조, 화면 요소 참조, 전국 17개 시·도의 고유 색상을 확인했다.

• 모의 도형으로 가장 큰 육지 선택, 내부 구멍 제외, 오목한 경계 내부 이름 배치 계산을 확인했다.

• 모의 이벤트로 커서·포커스 중복 진입, 장식의 마우스 감지 차단, 클릭 즉시 실행, 애니메이션 정리, 동작 줄이기 설정 시 선택 실행을 확인했다.

• 섬 표시 크기 변환, 작은 섬 필터링, 원본 경계 보존, 마커 좌표와 표시 경계의 일치 여부를 코드 수준에서 확인했다.

• 실제 브라우저 화면, 실제 GeoJSON 전체 데이터, MariaDB 연동을 포함한 종단 간 실행은 확인하지 못했다. 코드 검사 통과를 전체 기능의 실환경 검증 완료로 보지는 않는다.

• 입체 표현은 SVG 기반 2.5D 효과이다. 참고 사진의 산·수목·실제 지형 고도를 구현한 것은 아니다. 독도는 사용 중인 원본 GeoJSON에 경계가 있어야 표시된다.
