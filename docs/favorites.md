# 즐겨찾기 장소

장소 팝업에서 즐겨찾기 등록과 해제를 합니다. 왼쪽 패널의 ‘★ 즐겨찾기 장소’를 누르면 해당 회원이 등록한 관광지·맛집·행사만 지도 마커와 목록에 표시합니다. 전체 장소 보기로 돌아가려면 ‘전국’ 또는 ‘이전 단계’를 누릅니다.

- 회원별로 MariaDB의 `member_favorites`에 저장합니다. 동일한 회원·분류·장소는 중복 저장하지 않습니다.
- 테이블은 첫 조회 또는 저장 시 자동 생성됩니다. CREATE 권한이 없으면 관리자가 `db/member_favorites.sql`을 실행하세요. 기존 테이블은 삭제하지 않습니다.
- 즐겨찾기는 방문 기록과 별개로 저장되므로 등록·해제해도 방문 수가 바뀌지 않습니다.
- 마커는 기존 등장 애니메이션을 사용하며, 운영체제의 동작 줄이기 설정을 존중합니다.
- 테스트: `python -m unittest discover -s tests -p test_favorites.py`. 모의 DB로 권한, CSRF, 잘못된 입력, 중복 방지 쿼리, 회원별 등록·해제·목록을 검증합니다.
